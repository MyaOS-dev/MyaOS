# Official Syscall Catalog (v1.x)

Last updated: 2026-04-11

Source of truth for syscall numbers: `include/myaos/syscall.h`.

Status legend:

- `supported`: stable contract in v1.x
- `deprecated`: still supported in v1.x, but migration is required
- `unstable`: number is fixed, behavior may evolve during hardening
